## 二、单图/小批量测试步骤（0907 实测原样复现）

### 第 0 步 进入环境

浏览器打开开发机地址 → SSO 登录 → Ctrl+` 开终端，然后：

```bash
cd /mnt/kfs/bob/光影光效2
```

### 第 1 步 生成任务清单（实测约 30 秒）

```bash
python3 -u build_jsonl_lighting.py --batch 0818
wc -l batches/0818/Prompt_with_images.jsonl     # 实测 4278 行 = 1426 图 × 3 轮 ✓
```

### 第 2 步 抽取单图清单并出图（实测 3 张 43 秒）

```bash
# 抽出目标图的 r1/r2/r3 三行（换成你想测的图名前缀即可）
grep '丁达尔光-3.5-竖屏-1-r' batches/0818/Prompt_with_images.jsonl > test_one.jsonl
wc -l test_one.jsonl                             # 应为 3

python3 -u gen_image_lighting.py --batch 0818 --input-jsonl test_one.jsonl 2>&1 | tee test_log.txt
```

成功标志：进度条 `3/3 100%`；`test_work/260818-…-qt-round1/` 里出现
`{id}.png` 和 `{id}_colormatched.png` 各 3 张；`test_work/Prompt_with_images_0818.csv` 有 3 行数据。

> ⚠️ 结尾会报 `TypeError: shutdown() got an unexpected keyword argument 'cancel_futures'`
> ——这是 Python 3.6 不认识 3.9 的参数，发生在**出图全部完成之后**的线程池收尾，
> **无害，产物完整，不用管**。

### 第 3 步 几何对齐（实测 3 对 1 秒出头，全 crop）

```bash
/root/miniconda3/envs/comfyui-v4.0/bin/python -u skills/lighting-destyle-align/align_batch.py \
  --csv test_work/Prompt_with_images_0818.csv --workers 4
```

成功标志：打印 `完成 ok=… crop=… unaligned=…`，生成
`test_work/Prompt_with_images_0818_align_out/`（含 `processed/`、`align_all_results.csv`、`review/index.html`）。

> ⚠️ 用系统 `python3` 会直接报 `SyntaxError: future feature annotations is not defined`，
> 必须用上面 comfyui-v4.0 环境的 python。

（可选）人工审核：文件树右键下载整个 `_align_out` 到本机 → 双击 `review/index.html` 审核
→ 导出 `decisions.json` 拖回 `_align_out/` → 终端跑
`…/comfyui-v4.0/bin/python skills/lighting-destyle-align/align_batch.py --finalize --out "test_work/Prompt_with_images_0818_align_out"`。

### 第 4 步 交付 CSV（实测数秒）

成功标志：写出 `batches/0818/0818_光影_final.csv`，verify 打印

## 三、跑正式批次（放量前必读）

1. **改 work_dir**：现在 4 个配置文件（`batches/index.json` 和三个 `batches/*/config.json`）
   的 `work_dir` 都指向 `…/光影光效2/test_work`（测试用）。正式跑建议改成一个新目录，如
   `/mnt/kfs/bob/光影光效2/prod_work`：

   ```bash
   sed -i 's|/mnt/kfs/bob/光影光效2/test_work|/mnt/kfs/bob/光影光效2/prod_work|g' \
     batches/index.json batches/0818/config.json batches/0819/config.json batches/0819b/config.json
   mkdir -p prod_work
   ```

2. **耗时预估**：限速约 8 次/分钟 → 0818 批 4278 轮 ≈ **9 小时**；三批全跑 ≈ 26 小时。
   建议用 `nohup … &` 或分批挂机，断了重跑同一条命令即可续跑（已完成自动跳过）。

3. **全量命令**（与教程附录二一致，对齐一步换 python）：

   ```bash
   python3 -u build_jsonl_lighting.py --batch all
   nohup python3 -u gen_image_lighting.py --batch 0818 > log_0818.txt 2>&1 &
   # 0819 / 0819b 同理，跑完后：
   /root/miniconda3/envs/comfyui-v4.0/bin/python -u skills/lighting-destyle-align/align_batch.py --csv prod_work/Prompt_with_images_0818.csv --workers 4
   python3 -u make_lighting_delivery_csv.py --batch all --verify
   ```

4. **提示词可用性**：prompt 来自代码目录的 `prompts.json`（构建自提示词总表）。
   放量前对照 `D:\TP\提示词总表-通过清单.csv`——只跑**进度＝通过**的光效；
   总表若更新，需同步更新 `prompts.json` 再重新 build_jsonl。

5. **成品回传**：参照网盘 `0828` 的做法，把 `*-qt-round1/` 目录和 `*_光影_final.csv`
   拷到 `\\10.0.0.11\share\frank\光影图生图\<日期>\`。
