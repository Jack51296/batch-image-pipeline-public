# 光影光效2 全流程操作教程（小白版）

> 目标：从原图到交付 CSV，按顺序做完 4 大步。每一步都写清 **在哪个界面操作、敲什么、成功长什么样、失败怎么办**。
> 全程你只会用到 3 个界面，先认识它们。

---

## 〇、你会用到的 3 个界面

| 界面 | 长什么样 | 用来做什么 |
|---|---|---|
| ① 文件管理器 | Windows 的"此电脑"窗口（macOS 是"访达"） | 在本机核对代码包文件是否带齐 |
| ② 开发机网页版 VS Code（KML） | 浏览器里打开的 VS Code：左边是文件树，下方可以调出黑底终端 | **上传文件、敲所有 python 命令都在这里**。本教程说"在终端里"就是指它下方的终端面板 |
| ③ 浏览器普通页面 | 普通网页窗口 | 第 3 步人工审核对齐结果时打开 `review/index.html` |

**怎么打开开发机（网页版 VS Code）：**

1. 在浏览器（Chrome）里打开开发机地址：
   `https://devbox.example.com/?folder=/mnt/kfs/bob`
   （需在公司内网/VPN 环境，用公司账号登录。）
2. 打开后就是一个网页版 VS Code：**左侧文件树**当前定位在 `/mnt/kfs/bob`。
3. 调出终端：点顶部菜单 **Terminal（终端）→ New Terminal（新建终端）**，或直接按快捷键 **Ctrl + `**（Esc 下面那个反引号键）。窗口下方会出现黑底命令行，左边有 `用户名@机器名:路径$` 提示符 = 就绪。
4. 之后教程里的命令都是在这个终端面板里 **整行复制 → 粘贴（Ctrl+Shift+V 或右键粘贴）→ 回车**。

**两个必会常识：**

- `cd 路径` = 进入某个文件夹；`ls` = 列出当前文件夹里的文件。敲 `pwd` 随时能看自己在哪个文件夹。
- 命令里出现 `/path/to/你的代码目录` 或 `<你的账号>` 这种字样，都要**替换成你的实际路径**再回车，不能照抄。

## 第 0 步：上传代码包并自检

### 0.1 在【文件管理器】里核对代码包

打开你本机存放代码包的文件夹，对照下表逐个打勾，**缺一个都可能跑不下去**：

| 必带文件 / 文件夹 | 哪步用 |
|---|---|
| `build_jsonl_lighting.py` | 第 1 步 |
| `gen_image_lighting.py` | 第 2 步 |
| `make_lighting_delivery_csv.py` | 第 4 步 |
| `prompts.json` | 第 1 步（读 prompt） |
| `batches/index.json` | 全程 |
| `batches/0818/config.json`、`batches/0819/config.json`、`batches/0819b/config.json` | 全程 |
| `skills/lighting-batch-jsonl/`（整个文件夹） | 第 1 步 |
| `skills/lighting-delivery-csv/`（整个文件夹） | 第 4 步 |
| `skills/lighting-destyle-align/`（整个文件夹，里面必须有 `align_batch.py`、`align_core.py`） | 第 3 步 |

可选：`光影光效2-prompts.xlsx`（装了 openpyxl 才用得上；有 `prompts.json` 就不需要）。

### 0.2 上传到开发机【界面：开发机网页版 VS Code】

1. 在左侧文件树里找到（或右键 **New Folder** 新建）你的代码目录，建议：`/mnt/kfs/bob/光影光效2/`。
2. 在本机文件管理器里选中代码包的**全部内容**（含 `skills/` 三个文件夹），**直接拖拽到网页版 VS Code 左侧文件树的目标文件夹上**，等待右下角上传进度完成。
3. **`skills/` 三个文件夹必须整夹上传，不要只传单个 py 文件。** 上传完在文件树里展开核对一遍 0.1 的清单。

### 0.3 在【终端】里自检

在网页版 VS Code 里按 **Ctrl + `** 打开终端，逐行粘贴以下命令（`cd` 后面换成你的实际代码目录）：

```bash
cd /path/to/你的代码目录
python3 -c "import sys; print(sys.version)"
python3 -c "import requests; print('requests ok')"
python3 -c "import cv2, numpy; print('cv2 ok')"
ls -ld /mnt/kfs/bob/光影光效/h/mnt/kfs/bob/光影光效/260818-光影光效2-1426-qt-966-s35-460
ls build_jsonl_lighting.py gen_image_lighting.py make_lighting_delivery_csv.py prompts.json
ls batches/index.json skills/lighting-batch-jsonl skills/lighting-delivery-csv skills/lighting-destyle-align/align_core.py
```

**成功的样子**：版本号正常打印、两个 `ok`、`ls` 每条都列出文件名，没有出现 `No such file or directory`。

**失败怎么办**：
- `ModuleNotFoundError: requests / cv2` → 在终端跑 `pip3 install requests opencv-python numpy`（无外网就用公司内源或离线包）。
- `ls` 报 `No such file or directory` → 对应文件没传上来或路径敲错，回 0.2 补传，或用 `pwd` 确认自己在代码目录里。

### 0.4 确认盘上数据（不在代码包里）

| 数据 | 路径 | 说明 |
|---|---|---|
| 原图三批 | `/mnt/kfs/bob/光影光效/h/mnt/kfs/bob/光影光效/` 下的 `260818-…`、`260819-…` 两个、共三个文件夹 | 0818 / 0819 / 0819b 三批 |
| 出图目录 `work_dir` | 写在每批 `batches/*/config.json` 的 `work_dir` 字段里，例如 `/mnt/kfs/dave/chatgpt/光照/8.28` | 第 2 步往里写，第 3、4 步从里读 |

> 后面命令里的 `$WORK` 就是这个 `work_dir`。不确定就在终端里 `cat batches/0818/config.json` 看一眼。

## 第 1 步：生成任务清单 JSONL 【界面：终端】

**做什么**：扫描原图目录，为每张图生成 3 轮任务，写成 JSONL 清单文件。

```bash
cd /path/to/你的代码目录
python3 -u build_jsonl_lighting.py --batch all
wc -l batches/*/Prompt_with_images.jsonl
```

**成功的样子**：
- 屏幕输出里有 `exists: True`；
- `wc -l` 显示的行数 ≈ 该批图片数 × 3；
- 生成了 3 个文件：`batches/0818/Prompt_with_images.jsonl`、`batches/0819/…`、`batches/0819b/…`。

**失败怎么办**：`exists: False` 或行数是 0 → 原图路径不对，检查 0.4 的原图目录能否 `ls` 到。

---

## 第 2 步：API 出图 + 颜色追色 【界面：终端】

**做什么**：按 JSONL 清单调 API 出图，并对每张出图做 colormatch（**只调颜色，不动构图**）。

三条命令**逐条跑**（一条跑完再跑下一条；耗时较长，建议加 `tee` 留日志）：

```bash
cd /path/to/你的代码目录
python3 -u gen_image_lighting.py --batch 0818  2>&1 | tee log_0818.txt
python3 -u gen_image_lighting.py --batch 0819  2>&1 | tee log_0819.txt
python3 -u gen_image_lighting.py --batch 0819b 2>&1 | tee log_0819b.txt
```

**成功的样子**（产物都在 `work_dir` 里，`ls` 检查）：

| 产物 | 说明 |
|---|---|
| `{批次名}-qt-round1/{id}.png` | API 直出图 |
| `{批次名}-qt-round1/{id}_colormatched.png` | 颜色追色图 |
| `Prompt_with_images_0818.csv`（0819 / 0819b 同名类推） | pipeline 长表，一行 = 一轮（r1/r2/r3），**第 3 步对齐就用它** |
| `Prompt_with_images_*_out.jsonl` | 运行日志表 |

```bash
WORK=/mnt/kfs/dave/chatgpt/光照/8.28   # ← 改成你 config 里的 work_dir
ls "$WORK" | head
ls "$WORK"/*-qt-round1 | head
```

**注意**：中途断了直接重跑同一条命令即可（已完成的会跳过）；报网络/额度错误就看 `log_*.txt` 最后几行的报错原因。

## 第 3 步：几何对齐 【界面：终端 + 浏览器】

**做什么**：用 ORB 特征点 + 相似变换（缩放/旋转/平移），把 AI 出图对齐回原图的空间位置，必要时裁切。每对图的结果是三类之一：

- `ok` = 对齐成功；`crop` = 对齐后需裁切；`unaligned` = 对齐失败。

### 3.1 装依赖并跑对齐（终端）

```bash
cd /path/to/你的代码目录
WORK=/mnt/kfs/dave/chatgpt/光照/8.28   # ← 改成你的 work_dir

pip3 install -r skills/lighting-destyle-align/requirements-batch.txt

python3 -u skills/lighting-destyle-align/align_batch.py --csv "$WORK/Prompt_with_images_0818.csv"  --workers 4
python3 -u skills/lighting-destyle-align/align_batch.py --csv "$WORK/Prompt_with_images_0819.csv"  --workers 4
python3 -u skills/lighting-destyle-align/align_batch.py --csv "$WORK/Prompt_with_images_0819b.csv" --workers 4
```

**成功的样子**：每个 CSV 旁边多出一个 `_align_out` 文件夹：

```text
$WORK/Prompt_with_images_0818_align_out/
├── processed/               # 对齐后的图，文件名带 ok/crop/unaligned 标记
├── align_all_results.csv    # 对齐结果总表（含 unaligned）
├── aligned_candidates.csv
├── align_pair_details.csv
└── review/index.html        # 人工审核页
```

### 3.2 人工审核（浏览器，可选但建议做）

1. 在开发机网页版 VS Code 的**左侧文件树**里找到 `_align_out` 文件夹，**右键 → Download（下载）**，把整个文件夹下载到本机（必须整夹下载，`review/index.html` 要配合旁边的 `processed/` 才能显示图片）。
2. 在本机**双击 `review/index.html`**，会在浏览器里打开审核页：左右对比原图和对齐图，可翻页。
3. 逐页把不合格的对儿标掉，审完在页面上导出 `decisions.json`（浏览器会存到"下载"文件夹）。
4. 把 `decisions.json` **拖拽回**网页版 VS Code 文件树中对应的 `_align_out/` 文件夹里。
5. 回到【终端】执行导出：

```bash
python3 -u skills/lighting-destyle-align/align_batch.py --finalize --out "$WORK/Prompt_with_images_0818_align_out"
```

**成功的样子**：`_align_out/` 里多出 `aligned_for_label.csv`（最终可送标的表，相对路径）。0819 / 0819b 两批同样操作。

## 第 4 步：整理交付 CSV 【界面：终端】

**做什么**：按标签在直出图 / 追色图之间选型、修路径和扩展名，拼成 7 列交付表并自动校验。

```bash
cd /path/to/你的代码目录
python3 -u make_lighting_delivery_csv.py --batch all --verify
```

**成功的样子**：

```text
batches/0818/0818_光影_final.csv
batches/0819/0819_光影_final.csv
batches/0819b/0819b_光影_final.csv
```

表头固定 7 列：`id, prompt, input_image_path, output_image_path, output_image_path_1, output_image_path_2, 标签`；同目录会生成 `*_report.txt` / `*_verify.txt` 校验报告，打开确认没有报缺路径。

**交付口径二选一（问清要求再选）**：

| 口径 | 用什么交付 | 适用 |
|---|---|---|
| A（常用） | 上面的 `*_光影_final.csv` | 交付以出图/追色图为准 |
| B（强调几何对齐） | `_align_out/` 里的 `align_all_results.csv` 或 finalize 后的 `aligned_for_label.csv` | 交付必须用对齐后的 `processed/` 图 |

> 注意：A 口径的脚本默认取 `*-qt-round1/` 里的图；如果最终要求用对齐后的图，要么把 final 表里的 `output_*` 列替换为对齐结果路径，要么直接走 B。

## 附录三：常见报错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `No such file or directory` | 路径敲错 / 文件没传 | `pwd` 确认位置，`ls` 逐级排查 |
| `ModuleNotFoundError` | 缺 python 包 | `pip3 install 包名`（内网用公司源） |
| JSONL 行数为 0 | 原图目录路径不对 | 核对 0.4 的原图路径，`ls` 能列出才行 |
| 出图中断 | 网络/额度 | 看 `log_*.txt` 末尾报错；重跑同命令续跑 |
| 对齐大量 `unaligned` | 出图偏移过大 | 属正常筛除项，人工在 review 页复核即可 |
| 双击 `index.html` 打不开图 | `_align_out` 没整夹下载 | 连同 `processed/` 一起下载到本机 |
