# 图像工具

本仓库的浏览器图像工具，用于**批量跑图前的素材比例准备**和**交付前的尺寸 / 文件大小匹配**。
由 `image-ratio-crop-tool` 和 `image-size-matcher` 迁入，来源版本与改动见 [MIGRATION.md](MIGRATION.md)。

## 打开方式

- 在线使用：[统一工具入口](https://jack51296.github.io/batch-image-pipeline-public/)
- 本地使用：下载或 clone 本仓库，双击 `local_tools/image_tools/index.html`。
- 也可以直接双击 `ratio_crop/index.html` 或 `size_matcher/index.html`，每个工具都是独立页面。

使用工具无需安装 Python、Node.js、npm 或其他依赖，也无需启动服务器。推荐使用近期版本的 Chrome 或 Edge。
页面没有远程脚本、字体、统计或图片上传接口；图像在浏览器内处理，导出结果由浏览器下载。

> GitHub 仓库中的 HTML 链接展示的是源码；运行工具请使用上面的在线入口，或下载后在本地打开。

## 工具与适用场景

| 工具 | 输入 | 处理 | 输出 / 场景 |
|---|---|---|---|
| [比例裁剪](ratio_crop/index.html) | 一张图片 | 自动选择最接近的参考比例；最大整数像素区域裁剪；拖动调整位置 | 为横屏 / 竖屏 / 方形生成任务准备素材；导出 PNG、JPEG、WebP |
| [尺寸与文件大小匹配](size_matcher/index.html) | 原图 + 目标参照图 | 将原图缩放到目标宽高；按目标字节数搜索编码质量；不足时填充尾部字节 | 制作与参照图同尺寸、同文件大小的交付版本或测试样本 |

### 比例裁剪

1. 拖入或选择图片，工具读取尺寸并自动匹配比例。
2. 选择 `1:1、1:2、2:1、9:16、16:9、3:4、4:3、3:2、2:3、5:4、4:5、21:9、9:21` 中的一种。
3. 在预览画面中拖动，调整裁剪位置。
4. 选择输出格式，点击“下载裁剪图”。

最长边 **不超过 3000 像素**时，导出裁剪区域不缩放、不重采样；选择 PNG 可以保留该区域的像素值。
最长边 **超过 3000 像素**时，会先等比缩小到最长边 3000 以内，再执行裁剪。该步骤会重采样。
原图格式不属于 PNG / JPEG / WebP 时，“保持原格式”实际回退为 PNG。JPEG / WebP 会重新编码。

比例先约分，再计算最大整数区域。例如 `21:9` 等价于 `7:3`，160 × 120 的图像会裁成 154 × 66。
宽高不足以组成目标整数比例时，页面会提示“尺寸不足”并禁用下载。

### 尺寸与文件大小匹配

1. 选择需要处理的**原图**。
2. 选择**目标参照图**；工具读取其宽高、格式和文件大小，不使用目标图内容改写原图。
3. 保留目标实际字节数，或填写一个正整数字节数；选择自动或手动输出格式。
4. 点击“匹配并下载”，查看输出尺寸、文件大小与误差。

处理规则：

- 输出宽高固定为目标图宽高，允许放大或缩小。**两图宽高比不同时会拉伸原图**，不会裁剪或补边。
- 自动模式优先使用目标的 PNG / JPEG / WebP 格式；其他目标格式使用 WebP。同尺寸 PNG 超过目标大小时回退到 WebP。
- JPEG / WebP 通过编码质量搜索接近目标字节数，PNG 不支持这类质量调节。
- 有不超过目标大小的候选时，选择其中最大的候选，并追加尾部字节补足大小。**填充不提升图像质量**。
- 即使最低质量也超过目标，或指定 PNG 无法压到目标时，保留目标尺寸并显示文件大小误差。不会截断图像文件。
- 透明图片导出 JPEG 时会使用白色背景；PNG / WebP 支持透明度。

尾部填充的 JPEG / WebP / PNG 已在 Chrome 中验证可解码。严格的格式校验器或部分下游服务可能拒绝尾部多余字节；交付给此类系统前应验证其要求。
动画、EXIF / ICC 等元数据不作为本工具的保留目标；Canvas 导出的是静态图像。HEIC 等格式取决于浏览器是否能解码。

## 接入流水线

### 入库前：统一素材比例

```text
素材副本 → 比例裁剪 → 下载到新的批次素材目录 → 普查 / 转 PNG → JSONL 清单 → API 出图
```

保留原素材，将裁剪结果作为新批次的输入，再用已有 `skills/lighting-batch-jsonl/` 生成清单。
这两个浏览器工具按单张图片处理；本次迁移没有新增 Python 批处理接口或自动修改 `batches/index.json`。

### 交付前：按需匹配规格

```text
出图 / 追色 → 交付表 → 几何对齐 → 按需匹配尺寸与文件大小 → 检查图像对 → 交付
```

尺寸匹配是规格调整，**不替代 ORB 几何对齐、追色或交付表校验**。
对已配准的 `input / output` 对调整尺寸时，应让两张图使用相同目标宽高，重新核对配对关系、文件路径与清单。
对于像素风、线稿等依赖特定插值的任务，优先使用已有 `lighting-destyle-align` 的最近邻 / 双三次规则；浏览器匹配工具使用高质量平滑缩放，不提供风格专用插值。

## 浏览器回归测试（开发维护）

仅测试需要 Node.js 20+ 和 Playwright，使用页面本身不需要。

```sh
cd local_tools/image_tools
npm ci
npx playwright install chromium
npm test
```

Linux CI 使用 `npx playwright install --with-deps chromium`。本机已安装 Chrome 时，可跳过下载测试浏览器：

```powershell
$env:IMAGE_TOOLS_BROWSER_CHANNEL = 'chrome'
npm test
```

测试使用临时生成的图片，检查本地导航、13 比例最大整数裁剪、PNG 像素保留、拖动裁剪、3000 像素规则、三种格式解码、目标尺寸 / 字节数、PNG → WebP 回退和错误输入。
测试图片与下载产物在临时目录生成并清理，处理过程中检查没有 HTTP 图片上传或远程依赖请求。
